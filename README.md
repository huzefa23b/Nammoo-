# Namira × Huzefa — Ultimate Cinematic Experience

This is a static GitHub Pages website. No backend is required.

## VS Code
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html`.
4. Use Live Server, or open `index.html` directly in Chrome.

## GitHub Pages
Put `index.html`, `style.css`, `script.js` and the `assets` folder directly in the repository root.
Then:
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your URL should be:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
